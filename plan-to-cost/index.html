HandDrawn Floor Plan to 3D & Automated Cost Estimator

Bridge Between Computer Vision, Spatial Graph Detection, and Industrial Cost Engineering

The Industrial Problem: Closing the Gap Between Sketches & Estimates

In architecture, construction, and structural estimation, converting hand-drawn sketches or raw floor plan images into accurate 3D geometry and Bill of Quantities (BOQ) remains a manual, error-prone, and time-consuming task.

HandDrawn-to-3D & Cost Estimator automates this pipeline by combining an interactive canvas, continuous computer vision processing, wall segment graph extraction, and an automated cost engine. It translates 2D pixel coordinates into volumetric 3D structures and real-time material cost estimations.

Key AI & Engineering Capabilities

1. Dynamic Wall Sketching & Computer Vision Extraction

Features a web-based responsive canvas allowing users to draw freehand room layouts or upload floor plan images. The processing pipeline normalizes stroke vectors, detects intersecting wall segments, and enforces geometric closure constraints.

2. Graph-Based Room Topology & Volumetric Reconstruction

Utilizes cycle detection algorithms on wall adjacency graphs to identify closed room polygons. Once topology is verified, the engine extrudes 2D contours into 3D parametric meshes (calculating wall surface areas, room volumes, and boundary dimensions).

3. Automated Bill of Materials (BOM) & Cost Calculation Engine

Translates physical spatial parameters (e.g., surface area, wall thickness, ceiling height) into structured material unit rates. The engine automatically computes total required masonry, drywall, coating, and labor costs dynamically as the user modifies the drawing.

Technical Architecture & Tech Stack

Built with a modern, lightweight web-native architecture designed for low latency and interactive visualization:

  • Frontend & Canvas Engine: HTML5 Canvas API / JavaScript (ES6+) for real-time stroke vectorization and UI state management.
  • 3D Rendering Pipeline: WebGL / Three.js for client-side multi-view 3D mesh extrusion and spatial navigation.
  • Geometry & Graph Parsing: Custom graph parsing algorithms for room cycle detection and polygon triangulation.
  • Cost Integration API: Modular estimation backend mapping detected geometry to configurable unit pricing databases.
