Well-Watch Analytics Platform

Integrated Data Management System for Drilling Operations, Secure Archiving & Financial Workflow Validation (2015)

The Challenge: From Scattered File Servers to Controlled Knowledge

In drilling operations, Daily Reports, technical documents, invoices, claims and supporting files arrive continuously from multiple rigs. Traditional approaches rely on Windows File Shares and direct email distribution. This creates recurring problems:

  • Each rig sends reports directly to final users and must maintain its own recipient lists.
  • Office staff must manually archive and categorize received files.
  • Search is limited to folder browsing with high risk of data loss or unauthorized access.
  • No reliable activity log (who viewed, downloaded or modified a file).
  • Invoice and claim tracking depends heavily on individuals rather than system-enforced processes.

Well-Watch was designed as a central platform that automatically receives, archives, categorizes and distributes operational documents while providing structured search, controlled access and financial workflow enforcement.

System Architecture – Modules & Relations

The platform is built around a central Archive Viewer that acts as the single storage and integration base for all other modules.

  • Main Module / Dispatcher – automatic reception and distribution of reports
  • Archive Viewer – central secure storage and search engine
  • Invoice Tracking – full lifecycle of contractor invoices
  • Change & Claims – tracking of contractual changes and claims
  • Personnel Evaluation – monthly performance evaluation and reporting
  • Internal Messaging – controlled communication between users

Documents uploaded by users or received automatically are linked to the relevant Well, Contract and Invoice/Claim records, creating a coherent operational knowledge base.

Dispatcher: From Manual Email Chaos to Automated Distribution

Conventional Approach

  • Each rig sends reports/emails directly to final users.
  • Recipient lists must be updated manually and frequently.
  • Office staff must archive and categorize all incoming files.

Well-Watch Dispatcher

  • Rigs send all reports to a single “Data-Master” email center.
  • The system automatically distributes files to the correct final users according to rules defined by the administrator.
  • Archiving and categorization run continuously (24/7) without human intervention.

Result: Higher accuracy, significantly less manpower, and continuous operation.

Four Search Modules

All searches operate against structured metadata (Contractor, Contract, Well, File Type, Report Date) stored in a high-speed relational database.

  1. Simple Search – fast lookup by common fields
  2. Advanced Search – complex multi-criteria combinations
  3. Direct SQL Search – power users can execute optimized SQL queries
  4. 2D Map Search – click on the field map to locate wells and retrieve related reports geographically

Secure Archiving vs Traditional Windows File Shares

Aspect Windows File Share Well-Watch
Access Control Usually 2–3 broad levels defined by IT Pre-determined flexible access matrix per user and role
File Listing Users can list all files in accessible folders Non-listable storage – files only reachable via unique database addresses
Deletion Permanent deletion possible Soft delete only – files can be restored from internal recycle bin
Activity Log No reliable log of read/write/delete Full log of login, view, download, export and delete actions
Search One-level, slow folder search Four search modes including Direct SQL and 2D Map

Core Workflows (Rewritten)

1. Report Reception, Validation & Dispatch

Reports are received from rigs and field offices. The system checks whether the received reports meet the required validation criteria. If approved, they are automatically archived according to the predefined matrix and distributed to authorized final users (Karun, PPPL, etc.). If not approved, they are returned for correction or sent to the Tehran office for review.

2. Automatic Archiving & Distribution

Once validated, reports are:

  • Automatically archived based on the organizational matrix (Well / Contract / Report Type)
  • Automatically distributed via email to the correct distribution list defined by the administrator

3. End-of-Well Process & Export

When well operations are completed, the system can generate a comprehensive End-of-Well report package. Users can request a full export of all related documents. The system packages the files and delivers them via the requested medium (CD/DVD/HDD or network share).

4. Access Control Decision

Every request to view or download a report is evaluated against the user’s access matrix. If the user has the required permission for that Well / Contract / Report Type, access is granted; otherwise the request is denied.

Financial & Contractual Modules

Invoice Tracking

  • Upload of invoices, WPAs and all supporting documents
  • Full status tracking: Approved / Ongoing / Rejected
  • Management reporting per project including contract ceiling monitoring
  • Process is independent of individual persons – the system enforces the workflow

Change & Claims

  • Upload of all relevant letters, MoMs and supporting files
  • Status tracking: Started / Ongoing / Closed
  • Project-level management reporting and contract overview

Personnel Evaluation

  • Monthly performance evaluation of individuals
  • Complete historical record of all evaluations
  • Configurable reporting according to predefined hierarchy

Key Engineering Lessons

  1. Centralized Dispatch + Automatic Archiving eliminates manual distribution and categorization effort.
  2. Metadata + SQL Search is far more powerful than folder browsing for industrial document volumes.
  3. Non-listable storage + full activity logging materially improves security and auditability compared with traditional file shares.
  4. System-enforced workflows for invoices and claims remove dependency on individuals and increase compliance.
  5. Matrix-based access control allows precise permission design across roles and domains.
